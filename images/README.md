## 图片格式要求
- 格式：JPG 或 PNG
- 大小：建议单张不超过 500KB
- 命名：使用英文小写，多个单词用 `-` 连接

## 快速获取图片的方法

1. 打开学校官网或公众号
2. 找到需要的新闻或风景图片
3. 右键保存到本地
4. 调整尺寸后放入 images 文件夹
5. 确保文件名与代码中一致

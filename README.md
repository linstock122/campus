# 浙江水利水电学院 - 校园导览小程序（实验一）

## 项目分工

| 成员 | 负责页面 | 功能 |
|------|---------|------|
| A | index（首页）+ news（新闻） | 轮播图、学校简介、新闻列表、触底加载 |
| B | scenery（风光设施） | 图片网格、Flex布局、图片预览、设施状态 |
| C | message（留言） | 表单提交、留言列表、本地存储、小组介绍 |

## 开发规范

### 命名规范
- 页面文件夹：小写，如 `index`, `news`, `scenery`, `message`
- 组件：小写，多个单词用 `-` 连接
- 变量：驼峰命名，如 `newsList`, `swiperImages`

### Git 提交规范
```
feat: 添加新功能
fix: 修复bug
docs: 文档更新
style: 样式调整
refactor: 重构代码
```

### 每天工作流程
```bash
# 早上开始
git pull origin main

# 开发...

# 晚上提交
git add .
git commit -m "feat: 完成首页轮播图"
git push origin main
```

## 页面说明

### 1. 首页（index）
- 轮播图（swiper）展示学校通知
- 学校标志、名称、简介
- 导航到其他页面

### 2. 新闻页（news）
- 新闻列表（wx:for）
- 每项：标题、时间、点击量、图片、摘要
- 点击跳转详情
- 触底加载更多

### 3. 风光设施页（scenery）
- 图片网格（每行2-3列）
- 点击图片预览
- 设施名称、开放状态（绿色/红色标签）
- 关闭状态禁用点击

### 4. 留言页（message）
- 表单：姓名、位置、留言内容
- 提交验证
- 显示当前时间
- 留言列表展示
- 小组自我介绍（rich-text）

## 技术要点

- 不用云开发，数据存在本地（wx.setStorage）
- 全局样式统一（app.wxss）
- 页面间跳转（navigator）
